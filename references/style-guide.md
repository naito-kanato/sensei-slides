# ゼミスライドのスタイルガイド（既存デッキの実測と分析）

分析元: 過去のゼミデッキ2本（教科書の輪読のデッキ 38枚と、論文紹介のデッキ 16枚。デッキそのものはスキルに含まれない）。
両者は同じマスターを使う。例は、なるべく同梱の見本（`examples/zemi/`：論文紹介「重力波の初観測」）から引く。

## 1. ページ構成と寸法

- 16:9 ワイド（13.33 × 7.5 in）。白背景。
- **本文スライド** = レイアウト「タイトルのみ」
  - 左上に青い縦棒（0.24, 0.13）0.15×0.94 in ← レイアウトに含まれる
  - タイトル: (0.63, 0.28) 幅11.5 in、44pt 太字、灰色 545455、左揃え、1行
  - 下部の青帯: y = 6.76〜7.5 in、色 215F99（テーマ tx2 75%）← レイアウトに含まれる
  - 青帯の中の「まとめ文」: 白・太字・MS Pゴシック・中央揃え（プレースホルダー idx 13）
  - スライド番号: 右下、白文字
- **表紙・区切り** = レイアウト「1_タイトルのみ」（縦棒だけ、帯なし）
  - 題目: 中央、44pt 太字、節番号つきで1節1行（例: 「3.2 ばねの単振動」「3.3 減衰振動」）
  - 発表者名: 題目の下 (y≈4.98)、20pt
  - 複数の節をまとめて発表するとき、途中の節の頭にも同じ形の区切りスライドを入れる
- 本文エリア: x 0.4〜12.9 in、y 1.1〜6.62 in（青帯に絶対にかけない）
- 図をタイトルの右に置くときは y 0.35 から上詰めしてよい（タイトル文字の右端より右なら）

## 2. 文字の書式

| 要素 | 書式 |
|---|---|
| ●見出し | 「●」青 005AFF + 半角スペース + 見出し文、24pt、位置 (0.55, 1.14) |
| 本文 | 20pt、灰色 545455、Arial + MS Pゴシック（テーマフォント） |
| 強調 | 赤 FF0000（本文と同じ大きさ）。1枚に1〜3か所、そのスライドの結論や要点。語・数値のほか、**短い一文（全角20字まで）も可**（その枚の決め手の一文。1枚に1か所。場合分け・2つ並べた・展開（前 → 後）の枚は、塊ごとに1文で2か所まで）。強調の色は赤だけ（青で強調しない） |
| 小見出し・用語ラベル | 太字（例: 「チャープ質量：」「ひずみ：」。s.block・s.ask の既定） |
| 下線 | 聞き手に指してほしい語だけ（初めて出る固有名・図と対応させる語など）。**1枚2か所まで**（描画の検査が WARN）。小見出しには付けない |
| 補足の青字 | 213CFF。使うのは2つだけ：①図の色との対応（「{c:青の線}＝理論」）、②赤字の結論と並べる、もう一方の側（理論と実験、前と後）。語・数値だけにし、一文まるごとは青にしない。テンプレートの主色が青で見分けにくいときは、青字の代わりに下線か太字 |
| 変数 | イタリック。化学式・同位体は上付き/下付き（^{14}C, H_{2}O, CH_{4}） |
| 数式 | 画像（LaTeX風の Computer Modern）。本文と同程度の大きさ |
| 変数の定義 | 数式の右・同じ高さに「*m*：おもりの質量」「*k*：ばね定数」と縦に並べる。記号はイタリック、全角「：」で区切る。元デッキは20pt、18ptまで可。`s.defs(e.right + 0.4, e.y, [("m", "おもりの質量"), ("k", "ばね定数")])` |
| 矢印 | 水色のブロック矢印 4E95D9（右向き、0.6×0.55 in 程度）。「AだからB」の因果を図的に示す |
| 注目の輪 | 教科書・論文の図の注目点に重ねる赤 FF0000 の楕円、塗りなし、線 2.75pt、0.5×0.5 in 程度。`s.oval(x, y, w, h)`（見本の結果③：Fig. 4 右の GW150914 の点） |
| 表・流れ図の箱 | 見出しセル・箱は薄い青 DCE9F7 に青字 215F99、本文セルは薄い灰 F2F2F2 |
| 文中の帰結 | 「⇒」「→」を行頭に置く（例: 「⇒ 直接の観測はなし」） |

- **濃い青 215F99 の「面」は下部の青帯（とタイトル左の縦棒）専用。** 表の見出しや箱をこの色で塗ると、
  結論を書く青帯と同じ重みになって視線が分散する。本文中で使う塗りは淡色だけにする。

- 文字の大きさは 20pt（本文）/24pt（見出し）/44pt（タイトル）の3段のみ。18pt以下は図中ラベルと定義の補足だけ。
- 本文は箇条書き記号を使わない。インデント（字下げ）と行間で構造を作る。
- 文末に「。」を付けない。体言止め・「〜が出現」「〜を示す」のような短い言い切り。

## 3. 1枚のスライドの組み立て方

1枚 = 1トピック（教科書の1〜2段落、論文の1つの主張）。上から:

1. **タイトル** = 節番号＋節名（教科書）／「背景」「実験手法」「結果①」「考察」（論文）。同じ節の間は全スライド同じ。
2. **●見出し** = このスライドのトピック（10〜15字）。「2台で同じ信号」「波形が示す正体」。
3. **本文ブロック** 2〜5個。各ブロックは1〜3行。ブロック間は 0.3〜0.5 in 空ける。
   - 1行目を左 (x≈1.0〜1.5)、続く説明は全角スペースや 0.3 in の字下げで1段下げる
   - 教科書の文章を**要約して短い句に**する（全文の書き写しはしない）。1行は全角25字程度まで
   - 「前提 → 計算/現象 → 帰結」の流れ。帰結を赤字にする
   - 数式は主要なものだけ（導出の途中式は省くか1〜2本）
4. **図** は右側（x≈7.3〜12.8）。本文の左カラムと重ならないように。
5. **青帯のまとめ文** = このスライドを一言で（全角15〜26字、句点なし）。
   - 例: 「2本の腕の長さの差を、レーザー干渉計で読み取る」「雑音で偶然起きる頻度は、20万年に1回未満」
   - 「〜により〜」「〜が〜を示す」「〜の〜」など結論を名詞句で。●見出しの言い換えではなく**結論**を書く。
   - **青帯は本文を書く前に決める**（構成案の段階）。本文と図はこの一文を支えるためのもの。
     本文を書いてから要約すると、結論ではなく内容の要約になりやすい。
   - デッキ全体で、青帯だけを順に読むと節の話の流れになるようにする（例：`examples/zemi/outline.md` の「青帯だけを順に読む」）。

縦方向の目安（本文20pt）: 見出し 1.14 → 本文開始 1.9〜2.0 → … → 最終行の下端 ≤ 6.6。
1行の高さ ≈ 0.33 in。ブロック4つ×2行 + 間隔で ≈ 4.2 in。入りきらなければスライドを分ける。

### 文の形（体言止め）
スライドの本文は**名詞句で切る**。文章（「〜できない」「〜でいられる」「〜になってしまう」「合っています。」）は読み上げ原稿の文体で、
スライドに書くと「書き言葉みたいで簡潔でない」と見える。講義録や質問への答えを写すと文章調になりやすい。

| 文章調（直す前） | 体言止め（直した後） |
|---|---|
| 合っています。正確には「確率の高い語」を「1つずつ選ぶ」仕組み | 合っている：確率に沿って語を1つずつ選択 |
| AI は文献が実在するかを確かめられない ⇒ 出典をそのまま信じてはいけない | AI は文献の実在を確かめられず出典を信じられない → さらに「AI：文献の実在の確認なし ⇒ 出典は要確認」 |
| 時刻をずらせる ＝ 本物の信号が重ならないので雑音だけの背景でいられる | 時刻をずらす ＝ 雑音だけの背景（本物の信号は重ならない） |
| 検出には長い腕と高い感度の両方が要る | 検出に要るもの：長い腕 ＋ 高い感度 |
| 確率で選ぶので、同じ質問でも毎回同じ答えにはならない | 確率で選択 ⇒ 同じ質問でも答えが変わりうる |

- 行末を見る：動詞・助動詞（する・できる・ない・いる・れる・なる）や「。」で終わる行は名詞句に切り直す
- 「⇒」「＝」「：」で因果・定義をつなぐと、文にしなくても意味が通る
- 見本の本文（6節）はすべてこの形：「時空のひずみが光速で伝わる横波」「周期が短く振幅が増大」
- `check_layout.py` が文章調の行を WARN と一覧の「文章調」列で知らせる（目安 0 行）。問題・解答・添削のスライドは対象外

### 文字量の目安（ユーザーと合意）
- **本文は 100〜150字**（●見出し・タイトル・青帯・表のセル・図の注記は数えない）。180字・10行を超えたら目安超え、210字・12行が上限。
  実測：輪読・論文紹介の実際のデッキは、中央値 120字前後・真ん中の半分が 75〜150字・多い1割が 170字超。
  少なすぎも直す：70字未満（図が主役の枚は50字未満）の枚と、本文の枚の中央値が100字未満のデッキは check_layout が WARN（Codex の試作は中央値 66字で、中身の無い行で字数を埋めていた）。
- 「青帯にかからない」は収まりの条件にすぎない。収まっても目安を超えたら、聞き手が読み切れない量だと考える。
- **読みやすさは字数より形で保つ。** 過去の質問回答デッキは中央値138字で「文字が多い」「図との隙間がない」と言われたが、
  原因は文章調と1行23〜26字だった。18pt 以上・1行20〜25字・体言止め・塊（ラベル＋説明）に分ければ、150字でも読める。
- **1行の長さ**：図・表が横にあるスライドは全角18〜20字、図がなければ25字まで。長い行は図との間隔を食いつぶす
  （本文の右端と図の左端は 0.4 in 以上空ける。`check_layout.py` が ERROR で知らせる）。
- 削り方（180字を超えたとき）：式の導出・長い説明・補足的な条件・例外・文献名・教科書の言い回しの詳細を**発表者ノートへ移す**（口頭で補う）。
  根拠の数値・具体例は残す。それでも多ければスライドを分ける。
- `check_layout.py` が 180字超・10行超を「目安超え」、210字超・12行超を「多すぎる」、70字未満を「少ない」の WARN で知らせ、
  最後にスライドごとの一覧（字数・行数・最長行・図との間隔・図の縮尺）を出す。一覧に「←」の付いた行は直す。

### 文字だけのスライド（問題・解答・まとめなど）
- **文字だけのスライドでも本文は 20pt。** 18pt に落として詰め込むと3段の規則が崩れ、しかも上に寄って下半分が空く
  （以前の講座の問題・解答スライドで起きた）。
- 本文の最下端が y 4.5 in より上で、図も表もないなら、**2枚を1枚にまとめる**か、**行間（`gap`）を広げて縦に配分する**。
  上に寄せたまま下を空けない。`check_layout.py` が WARN「下が空いている」で知らせる。
- 逆に 20pt で青帯にかかるなら、上の「削り方」のとおり細部をノートへ移すか分ける（18pt にして収めない）。

## 4. 図の扱い

- **教科書の図**: スキャンから切り出し、紙の黄ばみを白に飛ばして貼る（`pdf_pages.py crop`）。図番号のキャプションは貼らない（必要なら本文で触れる）。
- **教科書に図がない話題**: 元デッキでは説明用のイラストや模式図を足している（回転する容器、仕組みの概念図など）。
  ここでは matplotlib（`figkit.py`）で模式図・概略グラフを描く。物理的に正しい形で、数値は本文や確かな値に基づく。概略図なら軸の目盛りを省くか「（概略）」と書く。
- 図は 1枚に1〜3個。主図は幅 4.5〜5.5 in。
- 数式の変数を図中で使うときは本文と同じ記号にする。
- 図の描き方（ユーザーの好み・色・線・立体の扱い・避ける質感・レシピ）は **`figures.md`** にまとめてある。

## 5. デッキ全体の構成

### 教科書の輪読型
- 表紙（節番号＋節名、発表者名）→ 本文スライドを教科書の流れの順に。
- 目次・まとめスライドは基本なし。ただし節の最後に教科書自身のまとめ（総括の図など）があればそれを最後の1枚にする。
- 枚数の目安: 教科書の段落1つで1枚（短い段落は2つで1枚）。教科書1ページ ≒ 2〜3枚。
  実績: 4節分で25枚、2節分で10枚、1節（約8.5ページ）で本文23枚。
- タイトルは全スライド「節番号 節名」（例: 「3.2 ばねの単振動」）。

### 論文紹介型

過去の論文紹介のデッキ（16枚）の実測。構成案の見本は **`examples/zemi/outline.md`**（重力波の初観測、表紙＋本文13枚を outline.md の表にしたもの）。

**流れと枚数（16枚の例）**
- 背景 4枚（1〜4）→ 論文の表紙 1枚（5）→ 背景 1枚（6、論文が扱う系）→ 実験手法 2枚（7〜8）→ 実験方法 2枚（9〜10）
  → 結果① 1枚（11）→ 結果② 2枚（12〜13）→ 結果③ 2枚（14〜15）→ 考察 1枚（16）。
  見本（14枚、発表20分）は少し短い版：背景 2枚 → 論文の表紙 → 実験手法 3枚 → 結果①②③ 各2枚 → 考察 1枚。
- 表紙より前の「背景」（1〜4）は論文の前提になる教科書的な話（その分野の基本の概念・先行研究の流れ）。
  **教科書の輪読のデッキの該当スライドを流用してよい**（同じマスターなので、そのまま入る）。
- 表紙より後の「背景」（6）は論文自身の導入（なぜこの系か）。ここから論文の内容。
- 「まとめ」「今後の課題」のスライドはない。考察（論文の最後の図）で締める。

**タイトル（左上）の付け方**
- 「背景」「実験手法」「実験方法」「結果①」「結果②」「結果③」「考察」。同じ段階が続く間は同じタイトル。
- 「実験手法」＝先行研究で確立した測り方の原理（見本ではレーザー干渉計で腕の長さの差を読む仕組み）、
  「実験方法」＝この論文の装置と手順（試料の作り方、装置の構成、測定の条件）。
- 結果は論文の図ごとに①②③…と番号を振る（結果①＝図1、結果②＝図2、結果③＝図3）。1つの図に2枚使うなら同じ番号。

**論文の表紙スライド（見本の4枚目）**
- レイアウト「1_タイトルのみ」（縦棒だけ、青帯なし）。
  `deck.title_slide(["Observation of Gravitational Waves", "from a Binary Black Hole Merger"], subtitle="和訳", author="著者名", bold=False)`。
- 英題：44pt、**太字でない**（教科書型の表紙は太字）、中央、2行で (2.04, 1.95) 幅 9.26 in。
- 和訳：28pt、中央、英題の下 y≈3.79。
- 著者名：20pt、中央、y≈5.37、全員を英語のまま（長ければ2行）。所属・雑誌名・年は書かない（ノートで触れる）。
  ただし、論文の図を使い、ライセンス（CC BY など）が書誌と DOI の表示を求めるときは、著者の下に雑誌・巻・頁・年・ライセンス・DOI を入れる（見本の4枚目）。表紙・区切り（●見出しの無いスライド）は、check_layout の文字量・行長の検査から外してある。

**本文スライド**
- 教科書型と同じ部品（●見出し、20pt 本文、赤字の結論、行頭の⇒、下線の用語ラベル、水色矢印、青帯）。
- 文字量：過去のデッキの実測は中央値 8行・145字前後（check_layout の数え方で 147字、最大 201字）。教科書型（6行・112字）より多めだが、
  新しく作るときも目安は 100〜150字（最大 210字）。
- 結果スライドの本文の型：「図の読み方（軸・記号・色の意味）」→「見えたこと」→「⇒ 解釈（赤字）」。
  例（見本の結果②、10枚目）：約 0.2 s で8周期、周期が短く振幅が増大 ⇒ 2つの天体の公転と合体（赤）／
  チャープ質量 約 30 M⊙ ⇒ 合計 70 M⊙ 以上（検出器の系）／一般相対論の数値計算と一致。
- **1枚の根拠で言えることだけを結論にする**：見本では、10枚目（波形）で言えるのは「2つの天体の公転と合体」まで。
  「ブラックホール」と言えるのは11枚目（75 Hz で回れる小ささ）からなので、結論を先取りしない。論文が「既知の天体では」と限るなら、そのまま限る
- 「結果」の青帯は「図Nから何がわかったか」。●見出しは図の量や話題の名前（「2台で同じ信号」）、青帯は解釈
  （「波形の変化から、2つの天体が回りながら合体したと判断」）にする。
- 記号は論文のまま（h, ΔL, M⊙）。●見出しや青帯にも記号を入れてよい。元デッキは数式オブジェクトで入れているが、
  このスキルでは青帯に画像を置けないので、Unicode（ΔL・M⊙）か「ひずみ h」と書く。
- 式は論文の主要なものだけ（1枚に1〜2本、`s.peq` / `s.prow`）。
- **1つの図に2枚使うとき**（過去のデッキの結果②・結果③）は、同じ図を同じ位置・大きさで置き、●見出しと本文だけ変えて話を進める（図は動かさない）。
  ただしこれは**2枚とも同じパネルについて話すときだけ**。2枚で話すパネルが違うなら、各スライドで話すパネルだけに切り分ける（下の「論文の図の扱い」）。
- 注意：python-pptx は数式入りのテキストボックス（mc:AlternateContent）を読めない。元デッキの数式入りのスライドが
  「図だけ」に見えるのはそのせいで、実物には見出し・本文・青帯がある。元デッキを調べるときは `render_check.ps1` の
  shapes.json（PowerPoint 実描画）を使う。

**論文の図の扱い**
- 論文PDFのページ画像から `pdf_pages.py crop --no-clean` でパネルごとに切り出す（カラー図なので `--no-clean`）。
  ページ画像は 400 dpi 程度で作る（PyMuPDF の `get_pixmap(dpi=400)`。200 dpi だと拡大したときに文字がにじむ）。
- **出典を図のすぐ下に書く**（`s.caption`。例「（Abbott et al., PRL 116, 061102 (2016), Fig. 2）」）。原稿の ※（出典）行だけでは足りない（スライドだけが人の手に渡ることがある）
- **そのスライドで話すパネルだけを載せる**。図全体を貼って「図(c)：…」と本文で指さない。
  過去の論文紹介のデッキでは、3パネルの図を2枚とも丸ごと貼り、話していないパネルが図の半分を占めていた
  → 各スライドで話すパネルだけに切り直した。
  パネルの中でも、話に要る部分だけでよい（見本の結果①は Fig. 1 の上段だけ、結果③は Fig. 4 の右だけ）。
  切り出しの端に隣のパネルの切れ端（枠線・目盛りの数字・円弧）が残ったら、そこだけ白で塗って詰める。必ず画像で確かめる
- **図の横に図の読み方を先に書く**：論文の図を置いたら、本文の1〜2行目に図の読み方（軸・記号・色の意味、量の定義）を書いてから結果を書く。
- **論文の図に、読み方の注記を足してよい**。PowerPoint の図形で重ねる（あとで編集できる。zemi.py）：
  - `s.note(x, y, "実測の波形", color=C.RED)`：白抜きのラベル（16pt、名詞だけ）。線の意味・点の群れの意味・数値（「傾き 0.14」「最大 1.0」）
  - `s.pointer(x1, y1, x2, y2)`：ラベルから注目点への矢印。補助線は `head=False, dash=True`
  - `s.oval(...)`：決め手の箇所の赤丸。`s.note(..., align="c")` でパネル名（「H1」「L1」）
  - 位置は、画像の中の点・線の位置を割合で読んで決める（numpy で黒い線の行・色の点の範囲を拾う。x ＝ 図の x ＋ 割合×幅）。
    白抜きがデータ点や軸線にかからない空きに置き、描画した画像で必ず確かめる
  - 色は図に合わせる（青い点の説明は青字、緑は緑字）。赤は結論に関わる1〜2か所。注記は1枚に5個まで
  - 名前が「注目の〜」の図形は check_layout の重なり検査と本文の字数から外れる
  図番号・キャプションは貼らず、本文で「図2B」「図B青」のように呼ぶ。
- 置き方と大きさ（過去のデッキの実測）：
  - 1枚：右に幅 4〜5 in。縦長のパネル列（A–C が縦に並ぶ図）は 4.2×5.0 in を (8.8, 0.14) からタイトルの右に上詰め。
    横長の装置図・スペクトルは幅 6〜6.8 in で右上 y≈0.2〜0.3。
  - 2枚以上：右に上下に重ねる（3.1×1.1／2.4×2.0／4.0×1.6 を縦に3つ。または、上に主図 5.2×4.1、下に装置図の再掲2枚、高さ 2 in）。
  - 前のスライドの図を小さく再掲して「どの図の話か」を示す（前の図を 3.2×1.8 で本文の右下に）。
  - **装置図は後で小さく再掲**して「いまどの段階の話か」を示す（考察のスライドに、実験方法の装置図を高さ 2 in で並べる）。
- 論文の図に自分でラベルを添えてよい（パネルの左に「濃度 小／中／大」、20pt）。
- 図の読み方（軸・色・記号の意味）を本文の最初の1〜2行で説明してから、結果を書く。
- **横に3〜6パネル並ぶ図**（比較のマップ・スペクトルの列）は、右に置くと文字が 7〜8pt になって読めない。
  全幅（幅 9〜12 in）で下に置き、本文は上に3〜4行（開始 y 1.75〜1.85）にする。各パネルの上に 20pt でパネル名（「条件A」「条件B」「条件C」）を添え、
  決め手になる箇所に `s.oval` を重ねる。上段と下段は別々に切り出して2枚に分ける
  （見本の結果①は、横長の Fig. 1 上段を全幅で本文の下に置いた形）。
- 図中の記号・凡例が小さくて読めないときは、本文か原稿で読み上げる（「左が H1、右が L1」）。

**聞き手が引っかかる所（論文紹介）**
過去の論文紹介のデッキでは、完成後レビューを通ったあとでも、発表者本人が読んで7つの質問をした。
どれも「スライドにも原稿にも答えがなかった」もので、ゼミでも同じ質問が出る。構成案レビューで専門外の目から引っかかりを挙げさせ、
妥当なものを流れの中に織り込む（`outline-review.md`「推論距離（専門外の引っかかり）の扱い」）。次の表は、その型と、見本（重力波の論文）に当てはめた質問と入れ方の例。
「単位・略語の初出」は種類が用語、それ以外は出どころ・論拠・比較・範囲の穴にあたる（outline-review.md の8）。

| 型 | 質問の例 | どこでどう答えるか |
|---|---|---|
| 単位・略語・記号の初出 | 「SN 比って」「M⊙ って」 | 初めて出るスライドの本文に一言（「SN 比（信号と雑音の比）」「M⊙：太陽の質量」）。本文に入らなければ原稿の最初の言及で言う |
| 信号の出どころ | 「その信号、地震や装置の雑音では？」 | 測った信号が、どこから・どんな過程で来たのかと、他から来たものと区別できる理由を、手法スライドの原稿で言う（離れた2台に同じ形で、到着の時間差つきで出る。片方の装置の近くの雑音は2台に同時には出ない） |
| 変わらなかった対照 | 「条件Bでは変わりません。ここから何が言える」 | 「変化なし」の結果を書いたら、必ず「⇒ 〜ではない／〜を外せる」を続ける（「条件Bは不変 ⇒ 原因はAではない」）。対照は結論を絞る根拠なので、事実だけで止めない |
| 手法の役目と行き先 | 「その手法、どのスライドで使ってる？」 | 1つの手法に役目が2つ以上あるとき（例：同じ測定を、量の定量と位置の決定の両方に使う）は、実験方法の表に「使う結果（スライド番号）」の列を足す。図の軸の量の出どころも原稿で言う |
| 量のスケール感 | 「10⁻²¹ のひずみって」 | 結論の数値には、比べる物差しを1つ添える（4 km の腕で ΔL ＝ 4×10⁻¹⁸ m ＝ 陽子の直径の数百分の一）。物理的な中身の補足が資料外なら ※（資料外の補足）に書く |
| 因果の範囲 | 「それが原因だと言える？」 | 考察で「論文が示したこと／示していないこと」を分ける。1条件だけの測定なら「原因が〜だとまでは示していない」と原稿に明記する。予測（理論計算など）との関係は、「矛盾しない」「条件を満たしていない」まで具体的に |

- 説明を別のスライドや質問一覧に分けない。前のスライドで先に触れる、「⇒」の1行、括弧書き、原稿の1〜2文で、話の流れの中で答えが出るようにする
- 専門外の聞き手（例：論文の分野の測定手法をふだん使わない研究室）を想定し、手法の基本（何を当てて、何を数えるか）は省かない

**正確さの落とし穴（論文紹介）**
過去の論文紹介のデッキの完成後レビューで、論文との食い違いが4か所見つかった。どれも本文を短く言い切るときに起きる。
書いたら、数値・手順・結論の1つずつについて次を論文の該当文で確かめる。
- **数値の帰属**：その数値は「何の」「どの検出器の」「いつの」値か。
  （誤：表のある手法の列に、別の検出器の角度を書いた。誤：処理の**前**の値を、処理の後の値として書いた → 「初期値」と書く）
- **手順の順序**：同時か、前後か。（誤：「Aを先に較正」→ 論文は "simultaneously"。同じ測定で同時に測っている）
- **結果と推論を分ける**：赤字の結論は、その図から言えることだけ。先行研究の理論や著者の推論は「（先行研究の理論）」と添えて黒字にする。
  **講師（発表者）の解釈**をスライドに載せるときは、その行に「（講師の解釈）」（発表は「（発表者の解釈）」）と添える。原稿で「これは講師の解釈です」と断っても、スライドだけを読む人には資料の事実に見える
  論文の動詞の強さ（explains／suggests／confirms）をそのまま写し、「示す」「確定」に強めない
- **別の量を1つにまとめない**：1つの現象が2つの信号に別々に効くとき（ある原子からの信号と、母体からの信号の変化）、どちらの話かを分けて書く
- **論文自身の誤記・食い違い**（図番号、本文と図の記号、"respectively" の対応が曖昧な数値）は、スライドでは確かな側に合わせ、原稿に ※（要確認）で残す
- **発表者の補足**（論文が突き合わせていない数値どうしの比較など）は、本文に載せず、原稿に「※（発表者の補足・論文の主張ではない）」で書く
- 背景・手法のスライドに概念図を足すのは教科書型と同じ（見本では2枚目の粒子の伸び縮み、3枚目の連星の軌道、5枚目の干渉計の模式図、11枚目の大きさの縮尺図、12枚目の時刻ずらしの模式図）。

## 判断に迷ったら

- 元デッキの見た目に寄せる。元デッキにない装飾（グラデーション、影、アイコン、装飾線）は足さない
- 1枚に詰め込みすぎるより分ける。本文が 6.6 in を超えるならスライドを分割
- 文字だけのスライド（問題・解答・まとめ）でも本文は 20pt。18pt に落として詰め込まない
- 資料の記述にない主張は書かない。補足するなら発表者ノートに ※（資料外の補足）で
