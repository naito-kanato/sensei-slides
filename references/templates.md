# テンプレートの見本を組む・テンプレートを作る

テンプレートを**選ぶ**だけなら SKILL.md 手順0 の「テンプレート」「色」の行で足りる。ここは、見本を組むときと、手持ちのスライドから新しいテンプレートを作るときの手順。

## テンプレートで見本を組む（「〇〇のテンプレで見本を組んで」と言われたら）

`examples/template` で `python build.py <名前>`（図はゼミの見本のものを使うので、先に `examples/zemi` で `python figs.py`）。
描画確認（SKILL.md 手順5）をして、画像を見せる。できた pptx はユーザーのフォルダの `見本/` に写す。
本文の形と図解の部品を1枚ずつ見せたいときは `examples/structures/` の `build.py`（`build.py テンプレート3`、色も `build.py テンプレート2 深緑`）。

## テンプレートを作る（「テンプレを作って」「テンプレを追加して」「このスライドをテンプレにして」と言われたら）

同梱の テンプレート1〜8（`assets/templates/`）は**変えない**。新しいテンプレートは名前を付けて追加する。**分析は部品がする**。
AI は自分の目で見た印象で色や位置を決めない（モデルで結果が割れるため）。部品の表を見せ、決まった質問だけをする。

1. テンプレートにしたいスライド（中身のスライドが入っていてよい）を、作業フォルダの `スライドテンプレート/` に置いてもらう。パスを言われたら、そこへ写す
2. `python <skill>/scripts/make_template.py --from-folder [--name 名前] [--source 元のファイル名]` を実行する。次の3つができ、`スライドテンプレート/テンプレート一覧.md` に追加される
   - `<名前>_テンプレート.pptx`：元のスライドからマスターとレイアウトだけを残したもの（中身のスライドは捨てる）
   - `<名前>_テンプレート.json`：見た目の設定。文字・強調・見出しの印・帯・薄い塗り・矢印の色、見出しの印（● ■ など）、まとめの帯の寄せ。zemi.py が読む
   - `<名前>_テンプレートの分析.md`：分析の表（約50項目と、研究発表の手引きの目安）

   あわせて **文字の組み方も数える**：`python <skill>/scripts/analyze_structure.py スライドテンプレート/`（本文の形の割合・結論の置き場・赤字の枚の割合）。
   出てきた「本文の形の割合」の1行を、その発表の設定の一覧（outline.md の `## オプション`）に写す。構成案で本文の形を選ぶときの目安になる（その人の組み方に寄せる）。
   見にくい枚・古い枚は `--skip 3,7-9` で外す（ユーザーに、手本にしたくない枚が無いか聞いてから）
3. **分析の表を見せ、次の3つだけを【質問】で聞く**（ほかは表のとおり）
   - 本文に使うレイアウトは「〇〇」でよいか（違えば、レイアウトの一覧から選んでもらう）
   - 下のまとめの帯は「元のスライドのもの」「描き足す」「無し」のどれか（表の「まとめの帯」の値を添える）
   - 強調の色は「〇〇」でよいか（違えば色を言ってもらう）

   手引きの目安から外れている所（文字が小さい・色が多い など）は、伝えるだけにする（元のスライドの好みとして扱い、勝手に直さない）
4. **試しに組んで見せる**：`examples/template` で `python build.py <名前>` → 描画確認 → 画像を見せる（同じ中身を テンプレート1 で組んだ画像と並べる）
5. 直したいと言われたら、次の表で直す。表に無いものは、元のスライドのスライドマスターを PowerPoint で直してもらい、2から作り直す

   | 言われたこと | 直す所 |
   |---|---|
   | 見出しの印の色・強調の色・帯の色・表の塗りを変えたい | `<名前>_テンプレート.json` の `colors`（BULLET・RED・BAND・PALE。値は RRGGBB） |
   | 見出しの印を変えたい（● を ■ に など） | `.json` の `heading_mark` |
   | まとめの帯の文字を左寄せ／中央にしたい | `.json` の `band_align`（`l`／無しで中央） |
   | 本文・表紙に使うレイアウトを変えたい | `スライドテンプレート/テンプレート一覧.md` の `### 名前` の「本文のレイアウト」「表紙のレイアウト」 |
   | タイトルの位置・大きさ・背景・ロゴ・帯の形を変えたい | 元のスライドのスライドマスター（PowerPoint で直して置き直し、2から） |

6. 選び方（頼むときに「テンプレートは〇〇で」。決めた名前はそのデッキの設定の一覧の「テンプレート」の行に入る）を伝える
   - 16:9（13.33×7.5 in）でないテンプレートは部品の位置がずれる。PowerPoint でスライドのサイズを 16:9 にしてから置き直してもらう
   - 下部の帯の枠が無いテンプレートでは、zemi が同じ位置に帯（`.json` の BAND の色の面と白い太字）を描く
   - 描画の検査は、自分で足したテンプレートの形を知らないので `check_layout.py ... --template <そのテンプレート.pptx>` を渡す
