# 話の筋（構成を決める前に書く）

青帯を1枚ずつ決める前に、デッキ全体の筋を1回だけ書く。資料の順に割り振るだけだと、話が「そして、そして」と並ぶだけになり、
聞き手は「なぜ今これを聞いているのか」を見失う。筋は、資料の順を崩すためではなく、資料の順の中に**問いと山場**を見えるようにするためにある。

決める順番：題 → **筋（この節）** → 構成の表（1枚1行・青帯を先に）→ 本文の形 → 本文と原稿。
上の段ほど抽象的で、下の段はその一文を支えるために決める（段階的詳細化。各枚の結論の一文だけを並べたものを先に作るのは、ゴーストデッキとも呼ばれる）。
**考える順は上から（ピラミッド）**：筋の4行 → 青帯の列 → 本文の要点と、それを支える事実（講座は事実の表の行、発表は要点の〔出どころ〕）。
具体の事実を先に集めてから筋を組むと、筋が集めた資料の形（沿革なら年代順）に引っぱられ、問いが弱くなる
（以前の講座で、裏取りを先に済ませた回は年代順の並びになり、問いが5枚目の原稿にしか出なかった）。
下の段で事実が上の段と合わなかったら、その枝の青帯と筋を直す。**見せる順**は別で、下の「答えの位置」で決める。

## 1. 筋の表（状況・複雑化・問い・答え）

構成の表の前に、次の表を書く（発表は outline.md の `## 話の筋`、講座は memo.md の1節の終わり）。check_outline・check_memo が見る。

| 筋 | 一文 | 枚 |
|---|---|---|
| 状況 | 聞き手が今知っていること・やっていることから（「重力波は100年前に予言された」）。講座なら学習者の仕事や経験（「あなたは約90の項目を S〜C で判定している」）。制度・歴史の題材でも、年代の最初からではなく「今の形」から入り、由来はあとの枚で | 2 |
| 複雑化 | それだけでは済まない事情（「しかし、直接とらえた人はいない」） | 2 |
| 問い | 複雑化から出る問い。疑問の形で終える（「地球に届く小さな揺れを、どうやってとらえるか？」） | 3 |
| 答え | 問いへの答え＝このデッキの主張の一文（「2台の干渉計が同じ波形をとらえ、偶然ではないと示した」） | 13 |
| 語り手 | 任意。誰の話として語るか（下の3節） | — |

- 4行（状況・複雑化・問い・答え）は必ず書く。本文5枚以下の小さな依頼は省いてよい
- 「枚」は、その一文を言うスライドの番号。**問いは本文の前のほう**（最初の3枚か本文の3分の1まで）に置く
- **答えの位置**（設定の一覧のオプション。check_outline・check_memo が見る）
  - **先**（発表の既定。Minto のピラミッド原則の結論から）：状況・複雑化・問いを短く言い、問いの枚か、そのすぐ後の枚で答えを言う。
    その枚の図は、答えを支える柱（あとの枚の青帯をまとめた2〜4個）の一覧。あとの枚は柱の順に根拠を示し、最後の本文の枚で答えを言い直して締める。
    聞き手は先に地図を持つので、途中で迷わない（ゼミ・学会・報告）
  - **後**（講座の既定）：前のほうで問いを立て、**答えは本文の後ろ3分の1**で回収する。学ぶ人が答えを取りに行く形
- **問いはスライドにも出す**：問いの枚には、問いの一文をスライドに1行載せる（赤字の短い一文でよい）。原稿で言うだけだと、見ている人には問いが残らない
- 答えは、論文なら著者の主張、教科書の輪読なら節の要点、講座ならこの回のゴールの1つ目に合わせる
- この4つは SCQ（Situation・Complication・Question、Minto のピラミッド原則の導入部）の形。答えが主張の一文になる

## 2. 前の枚から（そして・しかし・だから）

構成の表に「前の枚から」の列を足し、本文の枚ごとに、**前の本文の枚の青帯から、どの接続詞でつながるか**を「語（種類）」で書く
（例：「しかし（壁）」。本文の最初の枚は「—」）。語は3つだけ（ABT：And・But・Therefore、Olson）。種類は下の10個から選ぶ。

| 語 | 種類 | どんなつながりか | 青帯の書き方 | 原稿の1文目 | 次の枚・前の枚でやること |
|---|---|---|---|---|---|
| そして | 並べる | 同じ重さの項目を足す（工夫の1つ目→2つ目） | 足す項目そのもの | 「もう1つの工夫は〜」 | 3つまで。続くなら1枚にまとめるか、なぜ要るか（だから）でつなぎ直す |
| そして | 詳しく | 前の枚の一部を拡大する（全体→部品、主張→例） | 拡大した所で言えること | 「この中の〜を詳しく見ます」 | 前の枚のどこを拡大したかを、図か原稿で指す |
| そして | 次へ | 時間・手順の次の段に進む | 次の段で起きたこと | 「次に〜」「〜の後、」 | 同じ段の話を2枚に分けない |
| しかし | 壁 | このままでは足りない・できない | 壁そのものを言い切る（「差は陽子より小さい」） | 「しかし、ここに壁があります」 | 越え方を同じ青帯で言うか、あとの枚を だから（手段）にする |
| しかし | 意外 | 予想・常識と違う結果が出る | 違った結果を数値で言い切る | 「ところが、結果は〜でした」 | 前の枚か原稿で、聞き手に予想を先に立てさせる（「どちらだと思いますか」）。理由をあとの枚で だから（問い）で答える |
| しかし | 疑い | 反論・別の説明・偶然では？ | 疑いを言い切る（「雑音の偶然でも2台はそろいうる」） | 「ここで疑問が出ます。〜ではないか」 | あとの枚で確かめ方と結果を だから（帰結）で示す |
| しかし | 限り | ここまでしか言えない・例外・副作用 | 言える範囲を言い切る（「大きくしても答えは毎回変わる」） | 「ただし、〜までは言えません」 | 結論の枚の青帯を、この範囲に合わせる（言い過ぎない） |
| だから | 帰結 | 前の枚から言えることを言う（見えた→わかった） | わかったこと | 「ここから〜と言えます」 | 前の枚の何から言えるかを原稿で1文 |
| だから | 手段 | 前の枚の目的・壁のために要るもの・やり方 | そのやり方と、それで何ができるか | 「そこで〜を使います」 | 壁・目的の枚と、離れすぎない（3枚以内） |
| だから | 問い | 前の枚から出る問い（なぜ？どうやって？）に、この枚で答える | 問いへの答え | 「なぜ〜でしょうか」 | 問いを原稿の1文目で声に出す（情報の隙間） |

決まり（check_outline・check_memo が見る）
- 「そして」が4つ以上続いたら直す。装置の説明・手順のように、どうしても並べる所なら、outline.md に「つなぎの理由：…」と書く
- **「しかし」が1つは要る**。複雑化（筋の表）か、結果の山場を、青帯に出す。青帯は結論の一文のままでよい（疑問の形にしない）：壁・疑いそのものを言い切る
- **しかし（壁）・しかし（疑い）は出しっぱなしにしない**：次の「しかし」か本文の最後の枚までに、「だから」の枚が要る（越え方・確かめ方）
- 種類が無い・表に無い種類は直す（語だけだと、そしてが並べるだけか詳しくしているのか、しかしが何の山場か、レビューで分からない）
- 原稿の1文目は、上の表の言い方で前の枚からつなぐ。scaffold.py が原稿の目安に書き入れる

資料の種類ごとの、よくある並び（そのまま使わなくてよい。筋に合わせる）

| 資料 | 並び |
|---|---|
| 論文紹介 | 背景 →しかし（壁：未解決のこと）→だから（手段：この論文の方法）→そして（次へ：結果）→しかし（疑い：別の説明・偶然では）→だから（帰結：確かめた結果）→しかし（限り：言えないこと） |
| 研究発表 | 背景 →しかし（壁）→だから（手段：自分の方法）→しかし（意外：予想と違った結果）→だから（問い：なぜか）→しかし（限り：今後） |
| 教科書の輪読 | 節の問い →だから（手段：定義・式）→そして（詳しく：例）→しかし（限り：成り立たない場合）→だから（帰結：節のまとめ） |
| 講座 | 素朴な見方 →そして（詳しく：仕組み）→しかし（意外：素朴な見方が外れる所）→だから（問い：なぜ）→だから（手段：どう使うか） |

## 3. 問いを先に（情報の隙間）と語り手

- **答えの前に問いを置く**：何が分からないかが先に見えると、人は答えを知りたくなる（Loewenstein の情報の隙間）。
  山場の答えの枚の前に、本文の形「問い」の枚か、予想を立てる一言（「どちらが大きいと思いますか」）を置く
- **語り手**（任意）：誰の話として語るかを決めると、並んだ事実が物語になる
  - 論文紹介・研究発表：研究者が何に困り、何を試し、どこで壁に当たり、どう越えたか（壁＝「しかし」の枚）
  - 教科書の輪読：その節が答えようとしている問い（節の題を疑問の形に言い換える）
  - 講座：聞き手自身の疑問（「便利なのに、なぜときどき間違うのか」）。回のゴールに書いてある言葉につなげる
- 説得したい発表（研究の提案・予算の申請など）では、「今こうだ」と「こうなりうる」を行き来して最後に呼びかける形（Duarte の Resonate）もある。
  決まりにはしない。合うときだけ使う

## 4. 確かめないこと

面白いかどうかは採点しない（AI の採点はぶれる）。機械で見るのは、筋の4行があるか、問いが前にあるか、答えが「答えの位置」どおりか、
「そして」が何回続くか、「しかし」があるか、だけ。面白さは、見本と聞き手の反応（原稿へのコメント）で確かめる。

物語の形の文章は、説明文より理解も記憶もよい（Mar ほか, 2021 のメタ分析）。ただし、スライドの筋で測った研究は多くない。
