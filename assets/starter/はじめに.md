# sensei-slides（スライドを作るフォルダ）

このフォルダに、スライドを作るスキル sensei-slides が入っています。フォルダの名前は変えてかまいません（「ゼミ」「講座」など）。
**くわしい使い方は、このフォルダの `スキルの使い方.html`** をダブルクリックすると、ブラウザで読めます（はじめに.bat の最後にも開きます）。

## 使い方

1. **はじめに.bat をダブルクリック**します（Mac・Linux はターミナルで `sh はじめに.sh`）。仮想環境 `.venv` を作って部品を入れ、PowerPoint やフォントがそろっているかを確かめます。最初の1回だけです。
2. **このフォルダを AI エージェントで開きます**（Codex・Claude Code・Antigravity・VS Code の GitHub Copilot）。
3. **頼みます**：「生成 AI の使い方を一から教えて」「この教科書で全5回の講座を作って」「論文.pdf のスライドを作って」。

頼むと最初に、聞き手（講座ならあなた）がテーマにどのくらい詳しいか（初学者／多少知っている／かなり知っている）を聞かれます。これは必須です。続けて任意で、専門・研究テーマ・よく知っていることを聞かれます。書くと、言い換えと、聞き手が止まる所の見つけ方がよくなります。
資料（論文・教科書の PDF、研究発表なら結果の図・前の発表のスライド・メモ）は、このフォルダの一番上に入れて「入れたから、〇〇で作って」と頼みます。AI が中身を確かめてから、発表ごとのフォルダの `資料/` に分けて写します（元のファイルは残ります）。研究発表で目的・結果・結論がファイルに無いときは、チャットで聞かれます。途中のファイルは `_work/` にたまります。

## ツールごとの注意

- **Codex**：このフォルダを「信頼する」にします。`.codex/rules/` の決まりが読まれ、PowerPoint を使う3つの作業（描画の検査・PDF の書き出し・原稿のページ作り）だけが、確認なしで動きます。
- **GitHub Copilot CLI**：`.agents/skills/sensei-slides` を `.github/skills/sensei-slides` に写します（VS Code の Copilot は今のままで読めます）。
- 仮想環境を「有効」にしてから起動しなくてもかまいません。スキルが、このフォルダの `.venv` の Python を使います。

## 中身

| 場所 | 中身 |
|---|---|
| `.agents/skills/sensei-slides/` | スキル（Codex・Antigravity・VS Code の Copilot が読む） |
| `.claude/skills/sensei-slides/` | 同じスキル（Claude Code が読む） |
| `.codex/rules/sensei-slides.rules` | Codex で PowerPoint を動かす許可 |
| `はじめに.bat`・`はじめに.sh` | 準備（仮想環境と部品） |
| `スキルの使い方.html` | 使い方のページ |

使い方の説明は、一番上の `スキルの使い方.html` をブラウザで開いて読めます。

## スキルを新しくするとき

新しい一式の `.agents` `.claude` `.codex` の3つと `スキルの使い方.html` で、このフォルダの同じものを置き換えます。`_work/`・作ったスライドはそのまま残ります。
