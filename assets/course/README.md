# <講座名> — AI講座（sensei-slides の講座で作成）

<テーマ>を、講師のAIが <学習者の名前> さん専用に講義する連続講座。各回はスライド（`0N_<題>_スライド.pptx`）と
原稿HTML（`0N_<題>_原稿.html`：スライドと読み上げ原稿を横並びで読む）。読むのは原稿HTMLだけでよい。

## 学習者とゴール

- テーマへの詳しさ：<初学者／多少知っている／かなり知っている>（必須。各回の設計メモの1節に写す。回ごとに変えてよい）
- 学習者のプロフィール（任意）：<専門・研究テーマ・よく知っていること>（書くと、言い換えと止まる所の判定がよくなる）
- ゴール：<何ができるようになりたいか、使い道>
- 回数：全<N>回（1回ずつ作る。前の回のコメントと答えを読んでから次の回を作る）

## 原稿HTMLのコメント

- 書き出しの保存先: このフォルダ（<講座フォルダ名>）
- 講座ID: <XX>（コメントの書き出しファイル名の頭に付く。例 `<XX>01_<題>_コメント.json`。別の講座には別のIDを付ける）
- 原稿HTMLの「書き出し」でダウンロードフォルダに保存され、AI が読むときに講座ID「<XX>」のコメントだけをこのフォルダへ移す
- 質問への回答は別デッキ `0N_<題>_質問回答_スライド.pptx`・`_質問回答_原稿.html`。回答デッキへのコメントは同じ回答デッキの末尾に足す
- 確認問題への答え（「1-1 に答える」）は添削する。添削スライドには元の問題文も載せる

## 決め事（全回共通）

- 原稿は **AI講義モード**：話し手＝講師のAI、聞き手＝学習者（「あなた」と呼ぶ）。問いかけ、学習者の背景への橋渡しを入れる。
  確認問題は「あなたならどう答えますか」、答えの添削は「あなたは〜と答えました。〜」
- タイトルは全スライド「第N回 <題>」。構成：表紙＋本文（10〜15枚目安）＋確認問題（3問/枚）→解答（同じ区切り）
- 伏線は本文に青字「→ 第N回：…」。出典は原稿の ※（出典）行、確かめられなかったものは ※（要確認）行
- PDF は作らない（原稿HTMLがあるため）
- 記号・図の向き・色：<回を作るたびに足す>
